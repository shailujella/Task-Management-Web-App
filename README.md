# Tasklane

A fast, private task manager that runs entirely in the browser. No backend, no build step, no dependencies.

**Tech:** HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript (ES6+), Web Storage, Notifications API, HTML Drag and Drop API.

## Features
- Projects, plus Today and Next 7 days smart views
- Tasks with priority, due date, due time, status and notes
- List view and drag-and-drop Kanban board
- Reminders at the due time (in-app alert and optional browser notification)
- Live search, priority filter and a completion progress bar
- Undo for deleted tasks and projects, clear completed, JSON export and import
- Keyboard shortcuts (N new task, / search)
- Light and dark themes, responsive layout, accessible controls (labels, focus styles, reduced motion)
- Data stays on the device (localStorage)

## Run it
Open `index.html` in any modern browser.

## Project structure
- `index.html` page structure
- `style.css` design tokens, layout and themes
- `script.js` state, rendering, storage and reminders
