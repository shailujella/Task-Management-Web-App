# Tasklane

A task manager that runs in the browser. No build step and no dependencies.

## Run it
Open `index.html` in any modern browser. Tasks are saved in your browser (localStorage).

## Features
- Projects, plus Today and Next 7 days views
- Add tasks with priority, due date and due time
- List and board views (drag cards between columns)
- Search and priority filter
- Reminders when a task with a due time comes up (toast, plus a browser notification if allowed)
- Light and dark themes

## Files
- `index.html` page structure
- `style.css` styles and theme
- `script.js` app logic and storage
